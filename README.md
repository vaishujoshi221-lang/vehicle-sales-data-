 vehicle-sales-data-
vehicle sales data analysis using python , pandas , matplotlib and seaborn.
An exploratory data analysis (EDA) project analyzing vehicle sales trends, performance metrics, and revenue patterns using Python.

 🛠️ Tech Stack
- *Language:* Python
- *Data Manipulation:* Pandas
- *Data Visualization:* Matplotlib, Seaborn

 📊 Key Analysis & Visualizations (sales_charts.py)
- Sales performance across different vehicle categories and regions
- Monthly and yearly sales trend analysis
- Revenue comparison and top-selling models

 🚀 How to Run
1. Install required libraries:
   pip install pandas matplotlib seaborn

2. Run the script:
   python sales_charts.py

 📁 Dataset
- Vehicle sales dataset containing sales records, categories, and revenue metrics (sales_charts.py uses this dataset for analysis).

 💡 Key Insights
- Identified peak sales periods and seasonal trends across months/years.
- Compared revenue contribution across key vehicle categories and top-performing models.

 📂 Project Structure
- sales_charts.py – Python script for data analysis and chart generation
- README.md – Project documentation and setup guide
